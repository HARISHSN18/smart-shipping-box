I developed a Smart Shipping Box Recommendation System using Python, Django and Django REST Framework.
The main purpose of this project is to help warehouse staff choose the right shipping box for customer orders. The system checks the size and weight of the products and suggests a suitable box.
It includes product management, box management, order creation and an automatic box recommendation feature. I also created a simple dashboard using HTML, CSS and Bootstrap 5.
The system selects the smallest box that can hold all the products. If two boxes are suitable, it selects the one with the lower cost.
Through this project, I learned how to work with Django, create REST APIs, manage databases and solve real-world problems using Python.
